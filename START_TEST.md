# Одна команда для чистой распаковки

Сначала создайте облачный ChatGPT Project и откройте в нем новый Work-чат. Подключите Sites. Затем отправьте весь текст ниже. На компьютере участника ничего устанавливать не требуется.

```text
Разверни в этом облачном проекте мою личную систему «ГРУППА РОСТА» с нуля из https://github.com/bymaksimenko-stack/gruppa-rosta-personal-system . Скачай текущий main из GitHub в новую облачную папку и выполни INSTALL.md в режиме «чистый тест», используя Sites. Не используй прежние сайты, базы, установленные навыки или файлы с компьютера. Создай одну новую приватную тестовую копию и сохрани ее привязку для продолжения этой установки. В конце выдай два полных файла специалистов, настройку проекта, инструкцию и ZIP, а также команды запуска НОРДа и РИТМа в двух отдельных чатах этого проекта. Честно укажи, что выполнено, а что мне нужно добавить в Sources и настройки вручную.
```

При продолжении уже начатой установки агент обязан использовать сохраненную привязку этого прогона и не создавать еще один Site. Чистый тест не удаляет прежнюю личную систему и ее данные.

Для обычного участника после проверки замените слова «в режиме чистый тест» на «для личного использования». Полный порядок и команды двух специалистов находятся в INSTALL.md.
