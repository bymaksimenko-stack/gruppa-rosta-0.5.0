# Быстрый запуск

Для участника: следуйте [инструкции](docs/Участнику%20-%20установка.md), прикрепите установочный ZIP и скопируйте [текст задания](docs/PARTICIPANT_PROMPT.txt) в облачный Work своего проекта.

Для чистого теста можно явно добавить к заданию: «Это чистый тест, все сведения вымышленные; не заполняй систему до моего согласования». Чистый тест не удаляет другие системы.

Для продолжения сначала используйте сохраненный файл привязки. Повтор команды не является разрешением создать второй Site.

После подтверждения публикации 0.5.0 вместо архива можно указать URL публичного репозитория и поручить скачать текущий main с проверкой RELEASE.json. До этого используйте выданный установочный ZIP 0.5.0. Установочный агент выполняет INSTALL.md и сохраняет реальный источник.
