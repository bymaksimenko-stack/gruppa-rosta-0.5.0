# Команда для распаковки в облачном Work

Создайте облачный ChatGPT Project, откройте в нем Work с Sites и передайте текст ниже. После распаковки запуск специалистов идет из выданных файлов через «Файлы проекта».

```text
Разверни в этом облачном проекте мою личную систему «ГРУППА РОСТА» из https://github.com/bymaksimenko-stack/gruppa-rosta-personal-system . Получи текущий main в облаке и выполни INSTALL.md, используя Sites. Для этого чистого теста создай одну новую приватную копию; при продолжении уже начатой установки используй сохраненную привязку этого прогона. Выдай два полных файла специалистов: «01 - ГР - НОРД - Курс и годовая цель.md» и «02 - ГР - РИТМ - 12 недель и планы.md». Опубликуй их поддерживаемым механизмом файлов Work в этом проекте, чтобы я мог выбрать нужный файл в «Файлах проекта» и начать с ним отдельный Work. Дополнительно выдай «Как начать.md» и ZIP. Каждый файл должен содержать всю инструкцию, порядок запуска, обращения к личному плагину и восстановления памяти. Не добавляй обязательные шаги загрузки в общие Sources и копирования инструкций проекта для этого сценария. В конце назови фактический Site и личный плагин; отметь непроверенные этапы.
```

Для обычного участника вместо чистого теста укажите личную установку. При наличии своей существующей копии Site обновляется она; новый Site ради обновления инструкций специалистов не создается.
