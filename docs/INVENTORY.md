# Состав распространяемого комплекта

- Исходники сайта и бренд-материалы находятся в app/, components/, lib/, public/.
- Схема D1 и миграции находятся в db/ и drizzle/.
- Готовый устанавливаемый пакет НОРДа находится в plugins/gr-nord/.
- Исходные инструкции специалистов находятся в agents/; инструкция РИТМа пока не упакована в отдельный навык.
- Для локального клиента есть GitHub marketplace в .agents/plugins/marketplace.json.
- Для ручного варианта есть fallback/gruppa-rosta-local.html.

Исключены личные привязки Site, история Git разработчика, базы, окружения, токены, кэш, установленные зависимости, сборки и локальные отчеты с идентификаторами.
