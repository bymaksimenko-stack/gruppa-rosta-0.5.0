# Полнота авторских промптов — комплект 0.4.0

Предыдущий комплект 0.3.0 содержал сокращенные инструкции: 7308 знаков у НОРДа и 7021 у РИТМа. Они были ошибочно названы полными. Пользователь предоставил два настоящих промпта версии 0.4; именно они теперь являются источниками рабочих файлов.

## Сборка

Команда npm run generate:agents формирует самостоятельные файлы project/ из технического адаптера и полного исходного промпта. Команда python3 scripts/generate-specialists.py --check проверяет актуальность. Команда npm run package:project проверяет полный источник, соответствие рабочего файла генерации, UTF-8 и содержимое ZIP.

Полный авторский текст сохраняется внутри отмеченного блока побайтно: без удаления разделов, замены примеров, сжатия абзацев или пересказа. Для запуска Work не требуется читать дополнительные исходники: весь текст уже включен в файл специалиста.

## Границы

Новые промпты не добавляют отсутствующие инструменты хранения изображений, важности сфер, всех разделов Паспорта и ежедневных отчетов. Эти ограничения отмечены в самих промптах и адаптерах. Сайт, MCP-код, схема данных и личные записи от обновления инструкций не меняются. Результаты проверок и выдачи в облачном Work фиксируются после выполнения.
