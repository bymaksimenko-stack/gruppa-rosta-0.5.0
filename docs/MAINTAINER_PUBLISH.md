# Публикация публичного эталона

Целевой репозиторий: bymaksimenko-stack/gruppa-rosta-0.5.0. Не создавайте новый репозиторий или вторую систему.

1. Убедитесь, что используется собственная подключенная учетная запись владельца. В этой облачной среде нативные GitHub-вызовы во время подготовки возвращали Unknown tool; облачный git читает main, но push --dry-run запросил учетные данные. Успешная публикация изменений 0.5.0 этим не подтверждена.
2. Выполните проверки из README и убедитесь, что .openai/hosting.json не содержит project_id. Не отправляйте личные snapshots, runtime, .env, cookies, базу или файл привязки участника.
3. По последнему разрешению владельца оставьте репозиторий публичным. Не меняйте видимость на Private. Публичность разрешает чтение исходников; для push требуется собственная штатная авторизация владельца.
4. Отправьте подготовленные изменения в main обычным fast-forward push или через штатный GitHub connector. Не используйте force. При движении main сначала сопоставьте изменения и сохраните чужие правки. Резервный вариант: выданный patch применяется в актуальном клоне через git apply --check, затем git apply, проверки и обычный commit/push. Это действия в среде владельца с уже имеющейся авторизацией; переустановка CLI не нужна.
5. Перечитайте README, INSTALL.md, prompts/manifest.json, новый дизайн и текущий commit непосредственно из GitHub. Сверьте главные файлы с подготовленным комплектом; зафиксируйте полный SHA и фактическую видимость Public. Только после этого говорите, что GitHub обновлен.
6. Передавайте участникам установочный ZIP, текст PARTICIPANT_PROMPT.txt и памятку-картинку. После проверки публикации 0.5.0 можно использовать публичную ссылку на репозиторий. Не передавайте доступ к личному тестовому Site организатора.

Команды упаковки:

```sh
python3 scripts/generate-specialists.py --check
npm run check:template
npm run package:project
node scripts/check-dashboard.mjs
npm run check
npm run build
npm run package:install
```

Установочный ZIP содержит исходники и инструкции. ZIP project содержит только три файла запуска специалистов. Контрольные суммы авторских промптов неизменны, а ZIP новой версии имеет собственную контрольную сумму.
