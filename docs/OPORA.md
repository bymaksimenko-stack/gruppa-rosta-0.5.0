# ГР - ОПОРА: подключение к личной системе

Комплект 0.5.1 добавляет третий самостоятельный файл: `project/03 - ГР - ОПОРА - Коуч-сессии.md`. Номер помогает найти файл; ОПОРА доступна в любой момент, в том числе до НОРДа и до выбора цели. Это персональный ИИ-коуч системы «Группа роста» для разбора ситуации человека, затруднений и посильных экспериментов.

## Получение

Если система уже установлена, команда из [START_OPORA.md](../START_OPORA.md) получает один готовый файл из GitHub и выдает его поддерживаемым механизмом файлов Work. Установка второго Site не нужна. Можно также передать участнику сам MD. Он выбирает или прикрепляет его в отдельном Work своего проекта с уже подключенным личным плагином. Наличие файла не означает регистрацию глобального навыка или автоматическое подключение плагина.

## Что ОПОРА читает

`gruppa_rosta_v1_get_dashboard` того же личного подключения возвращает `{state, revision, updatedAt}`. Нужные для сессии сведения находятся в state: Паспорт и ограничения, маяк, память НОРДа, цели, спринт, текущая неделя, отчеты, колесо, сверки и при наличии tracking схемы v3. История диалога ОПОРЫ этим инструментом не возвращается.

ОПОРА не опрашивает человека обо всех пустых полях. Сначала работает с его сегодняшним запросом. Отсутствие цели не означает отсутствие мотивации; статус задачи не доказывает причину задержки; старый отчет может быть неактуален. При расхождениях задается одно относящееся к делу уточнение. В начале следующей сессии контекст перечитывается; после каждой реплики повторная выгрузка не нужна.

## Что сохраняется

В текущем Site 0.5.0, схеме 3 и проверенном списке MCP-инструментов нет отдельного хранилища итогов коуч-сессии. Согласованный итог ОПОРЫ остается в ее диалоге. Новому диалогу может потребоваться краткий переносимый итог прошлой встречи. Нельзя обещать общую память ОПОРЫ на Site по одному тексту инструкции.

Записывать итоги ОПОРЫ в nordMemory, отчеты РИТМа, Паспорт, задачи или сверки запрещено. ОПОРА помогает сформулировать запрос к соответствующему специалисту; это не автоматическая отправка сообщения или изменение данных. Для будущего постоянного хранения нужен отдельный контракт и явное согласие на конкретную запись. Этот комплект не меняет сервер, схему, существующие данные или опубликованные SQL-миграции.

## Расписание

Предложение ритма встреч факультативно. Если человек уже принес проблему, сначала обсуждается она. Напоминание или событие создается после согласования расписания и только фактически доступным инструментом. Если инструмента нет, ОПОРА дает текст для ручного действия, не сообщает о мнимом создании. Нового подключения Calendar или расписания при получении файла не создается.
