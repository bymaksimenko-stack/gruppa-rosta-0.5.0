# Установка из GitHub через браузерный ChatGPT Work

## Что участник делает сам

1. Создает личную копию репозитория либо предоставляет Work доступную GitHub-ссылку. Для приватного репозитория понадобится подключенный GitHub с доступом к нему.
2. Запускает Work в облаке и выбирает Sites и Plugin Creator. Передает ссылку и промпт ниже.
3. Проверяет возвращенные URL личного Site и результат установки навыка «ГР - НОРД». Если требуется действие владельца для установки или подключения, выполняет его в интерфейсе.
4. В новом чате выбирает установленного НОРДа и личный плагин данных. ChatGPT Project можно использовать для организации чатов; он не заменяет навык или постоянное хранилище.

В первой версии устанавливаемый пакет есть только у НОРДа. Для РИТМа пока есть инструкция в `agents/RHYTHM.md`; наличие второго устанавливаемого навыка не заявляется.

## Промпт для Work

```text
Разверни мою персональную систему «ГРУППА РОСТА» из этого GitHub-репозитория.

Сначала получи репозиторий из GitHub в свою текущую рабочую среду. Не используй пути с компьютера разработчика. Назови фактический источник, Git commit и рабочую папку; проверь наличие AGENTS.md, package.json и plugins/gr-nord/skills/gr-nord/SKILL.md. Полностью прочитай AGENTS.md и README.md.

Используй готовые исходники сайта, а не создавай другой сайт по описанию дизайна. У меня должна быть одна личная копия: приватный Site, личное D1-хранилище и личный MCP-плагин.

Проверь .openai/hosting.json. Если project_id уже есть, обновляй именно этот Site и не создавай новый. Если project_id нет, создай один Site с названием «ГРУППА РОСТА | ЛИЧНАЯ СИСТЕМА», сохрани его id в manifest и используй каноническое имя плагина «ГРУППА РОСТА | МОИ ДАННЫЕ».

Не переноси project_id, plugin_id, данные или токены другого участника. Если в полученной копии уже есть project_id, но не подтверждено, что это моя личная копия, сначала уточни принадлежность и не обновляй чужой Site.

Установи зависимости из lockfile, выполни npm run check и production build. Сохрани существующие миграции без изменения; новые генерируй только при изменении схемы. Затем опубликуй приватную версию. Проверь MCP server/discover и tools/list.

Собери готовый пакет НОРДа командой python3 scripts/package-nord.py. Проверь пять файлов ZIP и русское видимое имя «ГР - НОРД». Через Plugin Creator сохрани skills-only пакет в мой аккаунт, проверь диагностику компонентов и установи доступным поддерживаемым способом. Не создавай второй MCP-плагин поверх Site. Для личных данных используй плагин, созданный Sites.

Если create_plugin или другой необходимый механизм установки недоступен, останови только этот этап, назови точное недостающее действие и сохрани пакет. Не выдавай сборку ZIP или локальный marketplace за браузерную установку.

Проверь чтение контекста НОРДа. Тестовую запись можно делать только в выделенную память и только с моего разрешения; не заменяй мой маяк или реальные цели тестовыми значениями. После успешной записи перечитай контекст и проверь сохранение в Site.

Не объявляй автоматическое создание ChatGPT Project и двух чатов рабочим, если реально не выполнил его. В конце дай URL Site, plugin_url навыка, результаты импорта и тестов. Отдельно перечисли подтвержденное и оставшиеся действия. Автоматическую установку из GitHub считай пройденной только после фактического получения исходников, установки навыка и чтения памяти.
```

## Проверка после установки

В новом обычном чате выбрать плагин и попросить:

```text
Запусти «ГР - НОРД», прочитай мою сохраненную память через личный плагин данных и назови фактически полученные этап и следующий шаг. Ничего не меняй.
```

## Проверка локального клиента из GitHub

Это проверка получения и установки пакета в локальный клиент, а не браузерная установка:

```bash
codex plugin marketplace add https://github.com/bymaksimenko-stack/gruppa-rosta-personal-system
codex plugin add gr-nord@gruppa-rosta --json
```
