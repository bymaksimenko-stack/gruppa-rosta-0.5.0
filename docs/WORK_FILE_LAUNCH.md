# Запуск специалистов из файлов Work: 0.3.0

## Основание изменения

Пользователь сообщил о своем интерфейсном сценарии: Work выдает файлы в облачном проекте; в «Файлах проекта» он выбирает нужный MD и начинает с ним отдельный Work. Обязательная загрузка в общие Sources и копирование настройки проекта не требуются для этого пути.

## Подготовленный комплект

- «01 - ГР - НОРД - Курс и годовая цель.md» — полная стратегия и порядок восстановления памяти.
- «02 - ГР - РИТМ - 12 недель и планы.md» — полный порядок практической работы и обмена данными.
- «Как начать.md» — последовательность выбора файлов.

Каждый специалист читает свою полную инструкцию и данные личного Site. Наличие файла не считается установкой навыка меню. Просмотр файла не приравнивается к началу Work с ним.
