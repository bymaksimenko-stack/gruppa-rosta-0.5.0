# ГР - НОРД: статус первой версии

Готов пятифайловый пакет `plugins/gr-nord` с русским именованием, методологией и контрактом постоянной памяти. Проверялись структура, ссылки, UTF-8 и целостность ZIP. Локальная установка из каталога разработчика проходила; это не подтверждение браузерной установки из GitHub.

На тестовой личной системе проверялись постоянная память и восстановление из нового облачного чата через get_nord_context. Реальные данные участников в репозитории отсутствуют.

Для браузерного аккаунта необходимо фактическое сохранение и установка skills-only пакета поддерживаемым инструментом Plugin Creator. Доступность create_plugin зависит от текущей среды и проверяется до объявления установки успешной. В предыдущих тестовых средах он отсутствовал.

При недоступности механизма установки сохранить готовый ZIP и точную диагностику. Не создавать новый Site или дублирующий плагин данных для обхода этого ограничения.
