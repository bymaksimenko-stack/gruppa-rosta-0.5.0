# Ручной вариант без Work и Sites

Этот сценарий использует те же методологию и схему данных, но не обещает облачную синхронизацию.

## Запуск

1. Скачать репозиторий ZIP и распаковать.
2. Открыть `fallback/gruppa-rosta-local.html` двойным кликом в современном браузере.
3. Если ChatGPT Projects доступен в аккаунте, создать Project `ГРУППА РОСТА | <ИМЯ>`. Если недоступен — использовать два обычных отдельных чата.
4. В первый чат вставить содержимое `agents/NORD.md`, во второй — `agents/RHYTHM.md`.
5. После каждой значимой сессии попросить специалиста вернуть полный JSON-снимок и импортировать его в локальный дашборд.
6. Регулярно нажимать «Скачать копию» и хранить файл у себя.

## Ограничения

- специалисты не могут сами изменить локальный файл на устройстве участника;
- перенос между чатами и дашбордом выполняется вручную через JSON;
- очистка данных браузера может удалить `localStorage`, поэтому резервная копия обязательна;
- локальный HTML не получает автоматические обновления. Новую версию нужно скачать из GitHub и импортировать старую копию.
