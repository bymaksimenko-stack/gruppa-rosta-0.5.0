# Ваша личная ГРУППА РОСТА

Вам понадобятся ChatGPT с доступным режимом Work, Sites и установочный архив, который пришлет организатор. Ничего устанавливать на компьютер не нужно. Возможности зависят от аккаунта: если Work или Sites недоступны, сообщите организатору до установки.

## 1. Создайте свой проект

В ChatGPT создайте проект «ГРУППА РОСТА · Ваше имя». Откройте в нем новый чат, включите Work и выберите облачное выполнение, если интерфейс предлагает выбор. Используйте Sites для создания личного сайта.

## 2. Прикрепите архив и отправьте текст

Прикрепите к этому Work файл `gruppa-rosta-install-0.5.0.zip` от организатора. Вставьте целиком текст из соседнего файла `PARTICIPANT_PROMPT.txt` и отправьте. Самостоятельно распаковывать архив на компьютере не требуется.

Дождитесь отчета установщика: он должен выдать ссылку на ваш приватный сайт и файлы специалистов. Если Work просит подтвердить штатное подключение Sites, разрешите установку для своей копии. Не передавайте пароли или токены сообщением.

Исходный репозиторий остается публичным по решению организатора. Версию 0.5.0 можно получить из релиза или установить из публичного GitHub без входа; установщик сначала сверяет RELEASE.json. Ваш личный Site и его данные остаются приватными.

## 3. Подключите свои данные

Установщик назовет плагин вашего личного сайта. При необходимости установите или выберите именно его. Не подключайте сайт организатора или другого участника. Один проект, один личный Site и одно подключение данных используются обоими специалистами.

## 4. Начните с НОРДа

В своем проекте откройте «Файлы проекта». Выберите `01 - ГР - НОРД - Курс и годовая цель.md` для начала Work с этим файлом. Если интерфейс просит задание, напишите:

> Работай со мной как ГР - НОРД по выбранному файлу. Прочитай его целиком и сохраненный контекст моей системы. Ничего не сохраняй без согласования.

НОРД поможет определить курс, составить Паспорт роста и согласовать годовую цель. Полная инструкция уже находится в файле.

## 5. Продолжите с РИТМом

После согласования результатов НОРДа вернитесь в «Файлы проекта» и выберите `02 - ГР - РИТМ - 12 недель и планы.md` для отдельного Work. Используйте тот же личный плагин. При необходимости напишите:

> Работай со мной как ГР - РИТМ по выбранному файлу. Прочитай его целиком и результаты НОРДа в моей системе. Ничего не сохраняй без согласования.

РИТМ поможет выбрать результат на 12 недель и реальные действия на ближайшую неделю.

## Продолжение и дашборд

Общайтесь со специалистами в чатах. Подтвержденные изменения они сохраняют в личной системе. На сайте видны ориентир, цели, прогресс, баланс и текущая неделя. Для ручных правок есть «Редактировать» и «Сохранить».

История динамики начнется с ваших фактических показателей. Пустой график в новой системе нормален. Не требуется заполнять все карточки сразу.

Возвращайтесь в свои чаты или начинайте новый Work с файлом нужного специалиста. Для продолжения установки используйте прежний установочный чат и файл «Моя установка ГРУППА РОСТА.md», не запускайте вторую копию.

Общие Sources и ручная общая инструкция проекта не являются обязательными для описанного запуска через выбранный файл. Названия и расположение элементов могут отличаться в разных версиях интерфейса. Проверку телефона и доступности файлов на вашем аккаунте проводите отдельно.
