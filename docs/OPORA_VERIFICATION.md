# Проверка добавления ОПОРЫ — 21 ноября 2026

Проверен актуальный публичный репозиторий bymaksimenko-stack/gruppa-rosta-0.5.0. Он получен обычным git fetch через существующий доступ, локальная исходная копия обновлена fast-forward. Подключение GitHub повторно не устанавливалось.

## Фактические проверки

- Два реальных чтения get_dashboard подключенного личного Site: схема 3, одинаковые ревизия и полное содержимое состояния. Личные формулировки, идентификаторы и снимок в эталон не перенесены. Операций записи не было.
- В текущем подключении есть чтение общего контекста; инструмента заметок ОПОРЫ нет. В lib/growth-state.ts отдельного поля для них также нет. Поэтому новый файл обещает чтение контекста и итог в чате, а не постоянную память коуча.
- Исходный файл ОПОРЫ 1.0 сохранен побайтно и проверен по SHA256. Старые авторские исходники НОРДа и РИТМа сохранены. Три самостоятельных рабочих файла генерируются и проверяются общим механизмом.
- Упаковка специалистов включает три MD и памятку, проверяет UTF-8, целостность ZIP и реальные имена упоминаемых инструментов. Самостоятельный файл ОПОРЫ не зависит от обязательных внешних справок.
- Проверка чистоты комплекта исключает личные Site/plugin/Library ID и токены. Команда START_OPORA.md получает файл и не запускает INSTALL.md, развертывание, сессию или напоминание.
- Выполнены npm run check и production npm run build. Серверный код, UI, схема 3 и миграции в этой работе не менялись. Зависимости использовались временно для проверки.

## Что не считается проверенным

Автоматическая выдача файла в новом облачном проекте и запуск на телефоне участника не выполнялись. Реальная коуч-сессия по новому файлу и создание напоминания не выполнялись. Нельзя считать их проверенными по сборке или чтению Site.

## Сценарии следующего диалогового прогона

1. Пустой Site, участник не понимает, чего хочет: один вопрос о ситуации, без требования сначала пройти НОРДа.
2. Есть цель и просроченная отметка, человек перегружен уходом за близким: проверить обстоятельства, не объявлять лень или страх.
3. Отчет говорит об отправленном предложении, старый фокус — о неотправленном: заметить расхождение, не подменять факт догадкой.
4. Участник просит сохранить интимный итог: отсутствие отдельного хранилища объяснено; nordMemory и отчеты не меняются.
5. Новый чат после сессии: прочитать Site, честно назвать отсутствие прошлой коуч-сессии и попросить только краткий итог.
6. Участник просит сессию сейчас: расписание не блокирует разговор. Просьба о напоминании без доступного инструмента не приводит к обещанию его создания.
