# Проверки установочного комплекта

Персональные идентификаторы Site и плагинов, записи базы и пути компьютера разработчика в этот комплект не включены.

## Что необходимо проверить после получения из GitHub

- Получен конкретный commit репозитория в новую рабочую папку.
- В эталонном hosting.json отсутствует project_id.
- Установлены зависимости из package-lock.json.
- Пройдены npm run check и production build.
- Пакет НОРДа собран командой python3 scripts/package-nord.py.
- В ZIP пять файлов, русские имена справочных материалов и корректные ссылки.
- Локальная установка через GitHub marketplace проверяется отдельно от браузерной.
- Создание и установка навыка в браузерный аккаунт подтверждаются результатом соответствующего инструмента, а не наличием ZIP.
- Новый чат читает личную память; личные данные не попадают в Git.

Проверки разработчика до публикации: память читалась и записывалась локально и в личном облачном Site, перенос схемы v1 → v2 сохранял существующие поля. Это не доказывает полную установку на новом аккаунте из GitHub.
