# Данные и приватность

## Что хранится

- маяк: название курса, горизонт, желаемое и факультативное нежелательное будущее;
- Паспорт роста: точка А, сильные стороны, ограничения, ценности, видение на 3–5 лет;
- годовая цель и критерий результата;
- текущий 12-недельный спринт;
- недельный фокус, нагрузка и задачи;
- недельные отчеты;
- колесо жизни;
- четырехнедельные сверки курса.
- память продолжения НОРДа: краткий подтвержденный итог, этап, следующий шаг, открытые вопросы, источник и время записи. Это ограниченная память текущей работы, а не полный архив переписок.

## Изоляция

- Site публикуется приватно для владельца.
- Каждая запись привязана к стабильному site-scoped `oai-authenticated-user-id`.
- MCP-запросы проходят проверку доступа Sites, операции записи требуют идентифицированного пользователя.
- Email хранится как служебный атрибут владельца. Он не выводится в интерфейсе и не передается другим участникам.
- В коде, manifest и Git нет токенов, паролей или секретов.

## Резервные копии

Кнопка «Скачать копию» создает JSON на устройстве пользователя. Восстановление сначала загружает копию как черновик; запись происходит только после отдельного «Сохранить». MCP-восстановление требует `confirm=true`.

## Ограничения

- В MVP нет сквозного шифрования текста поверх хранения Sites/D1.
- Не следует сохранять медицинские диагнозы, пароли, платежные данные и другие секреты.
- ИИ не является врачом, психотерапевтом или гарантом результата.
- Этот Site не публикует личные записи группе.
