# Запуск первого специалиста

После распаковки в облачном проекте откройте «Файлы проекта» и выберите **01 - ГР - НОРД - Курс и годовая цель.md** для начала нового Work. Полная инструкция уже содержится в файле. Личный плагин данных должен относиться к вашей копии Site.

Если вместе с выбранным файлом нужен текст задания:

```text
Работай со мной как ГР - НОРД по выбранному файлу. Прочитай его целиком и восстанови мой этап и следующий шаг через личный плагин. Если памяти нет, начни знакомство. Ничего не записывай без моего подтверждения.
```

[Как начать](project/Как%20начать.md) объясняет переход от НОРДа ко второму специалисту. Общие Sources и установленный навык меню для данного пути не обязательны.
