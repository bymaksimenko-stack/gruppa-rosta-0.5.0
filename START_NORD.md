# Запуск первого специалиста

Основной путь теперь — [два файла в одном облачном проекте](project/Как%20начать.md). Первый файл: [01 - ГР - НОРД.md](project/01%20-%20ГР%20-%20НОРД.md). Он содержит всю инструкцию и не требует импорта навыка.

Для разового запуска из GitHub в облачном Work с подключенным личным плагином:

```text
Получи https://github.com/bymaksimenko-stack/gruppa-rosta-personal-system в текущую среду. Прочитай целиком «project/01 - ГР - НОРД.md» и запусти ГР - НОРД по этой инструкции. Сначала прочитай мою сохраненную память через личный плагин и назови фактический этап и следующий шаг. Ничего не записывай. Не заявляй установку глобального навыка или добавление файла в источники проекта.
```

Разовый запуск в Work не добавляет инструкцию в Project Sources для других чатов. Для постоянного проекта добавьте два файла и настройки по основной инструкции.
