# Запуск «ГР - НОРД» из GitHub

Этот способ загружает готовые инструкции НОРДа в текущий облачный Work. Он не регистрирует глобальный навык в меню `@` и не заменяет поддерживаемый импорт плагина. В новом чате инструкцию потребуется повторить, а личный контекст НОРД прочитает из постоянного хранилища.

Перед запуском у участника должен быть развернут собственный личный Site и подключен его плагин данных. Исходники проекта доступны всем, личная память участника остается в его приватном Site.

Откройте новый облачный Work-чат, выберите свой личный плагин данных Группы роста и передайте сообщение:

```text
Запусти специалиста «ГР - НОРД» из публичного репозитория https://github.com/bymaksimenko-stack/gruppa-rosta-personal-system.

Получи исходники в текущую рабочую среду и прочитай plugins/gr-nord/skills/gr-nord/SKILL.md, agents/openai.yaml и обе справки из references/. Используй эти готовые инструкции; не придумывай другую методологию.

Сначала вызови доступный инструмент моего личного плагина данных gruppa_rosta_v1_get_nord_context. Восстанови фактически сохраненные этап, итог и следующий шаг. Если памяти нет, начни знакомство. Если подключения нет, сообщи, что прочитать память не удалось. Ничего не записывай без моего поручения или подтверждения.

Это запуск инструкций из GitHub в текущем Work. Не заявляй, что глобально установил навык или что он появился в меню @.
```

Для настоящей установки пакета используйте готовый ZIP из [версии 0.1.0](https://github.com/bymaksimenko-stack/gruppa-rosta-personal-system/releases/tag/v0.1.0) и поддерживаемый механизм импорта Plugin Creator. Его доступность и успешность установки проверяются отдельно.
