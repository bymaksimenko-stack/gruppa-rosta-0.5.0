# Добавить «ГР - ОПОРА» в существующий проект

Это команда скачивания одного готового специалиста. Она не запускает установку нового Site. Скопируйте в Work своего облачного проекта:

```text
Получи актуальный main публичного репозитория https://github.com/bymaksimenko-stack/gruppa-rosta-0.5.0 и прочитай START_OPORA.md. Мне нужен готовый файл project/03 - ГР - ОПОРА - Коуч-сессии.md целиком, без пересказа. Проверь его по prompts/manifest.json командой python3 scripts/generate-specialists.py --check. Выдай этот MD штатным механизмом файлов Work как доступное мне вложение, сохрани реальную ссылку/идентификатор, если они возвращаются. Одного пути в облачной папке недостаточно. Используй существующую личную систему этого проекта; новый Site, плагин и расписание не создавай, личные данные не меняй. Если выдача файлов недоступна, сообщи ограничение и дай ссылку на этот файл в GitHub. Сейчас только получаем файл, коуч-сессию не начинай. После выдачи коротко объясни, как выбрать файл для отдельного Work с уже подключенным личным плагином своего Site.
```

После получения выберите **03 - ГР - ОПОРА - Коуч-сессии.md** для отдельного Work и подключите свой личный плагин данных. Если интерфейс просит задание, достаточно:

```text
Работай со мной как ГР - ОПОРА по выбранному файлу. Прочитай его целиком и доступный контекст моего личного Site. Хочу разобраться, что сейчас мне мешает и с чего начать. Ничего не сохраняй и не создавай напоминаний без согласования.
```

Для начала ОПОРЫ не обязательно завершать НОРДа или РИТМ. Файл не устанавливает глобальный навык меню. Если выбрать файл в данном интерфейсе нельзя, прикрепите скачанный MD к отдельному Work и используйте короткое задание выше. Само скачивание не доказывает доступность файла в новом чате; полный текст и личное подключение проверяются при запуске.
