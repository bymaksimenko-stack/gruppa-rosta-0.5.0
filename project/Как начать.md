# Как запустить специалистов из файлов Work

Версия комплекта: 0.5.0. Файлы специалистов включают полные авторские промпты версии 0.4: у НОРДа 581 строка, у РИТМа 821 строка, без сокращения методологии. Отдельное техническое предисловие описывает подключение к текущему Site. Рабочий сценарий — облачный ChatGPT Work внутри личного проекта. Установщик получает код из приложенного установочного ZIP или доступного ему GitHub, создает личный Site и выдает готовые файлы специалистов в этом проекте.

## Сначала распаковка

Создайте облачный проект и откройте в нем Work с Sites. Прикрепите установочный ZIP и передайте текст из docs/PARTICIPANT_PROMPT.txt. В конце установщик должен выдать два отдельных полных Markdown-файла и назвать личный плагин данных. ZIP — дополнительная резервная копия, а не обязательный этап запуска.

## 01 — сначала выбрать курс

В своем проекте откройте «Файлы проекта», выберите **01 - ГР - НОРД - Курс и годовая цель.md** для начала нового Work и работайте с этим файлом. Убедитесь, что доступен личный плагин именно вашего Site.

Полная инструкция уже находится в файле. НОРД должен прочитать ее, прочитать сохраненную память через личный плагин и продолжить с фактического этапа. Если памяти еще нет, начнет знакомство. Копировать весь промпт в сообщение и предварительно добавлять файл в общие Sources для этого пути не требуется.

Если интерфейс ожидает текст задания вместе с выбранным файлом, достаточно: «Работай со мной как ГР - НОРД по выбранному файлу».

## 02 — затем перейти к действиям

После согласования курса и годовой цели вернитесь в «Файлы проекта» и выберите **02 - ГР - РИТМ - 12 недель и планы.md** для отдельного Work. Используйте тот же личный плагин данных.

РИТМ читает сохраненные результаты НОРДа из Site, продолжает спринт и неделю либо помогает сформировать первый план. Пересылать всю переписку между специалистами не нужно. Если исходные данные не сохранены, он должен назвать недостающее, а не придумать цель.

При необходимости короткое задание вместе с выбранным файлом: «Работай со мной как ГР - РИТМ по выбранному файлу».

## Продолжение

Можно вернуться в существующий чат. Для нового Work снова выберите файл нужного специалиста: он перечитает инструкцию и личные итоги из Site. Одну длинную переписку хранить как единственный источник памяти не требуется.

Личные цели, планы и подтвержденные итоги хранятся в приватной базе Site. Файлы специалистов содержат общую методологию, не биографию участника. Новый файл с копией промпта после каждой беседы не создается.

## Если что-то недоступно

Если выбранный файл доступен только частично, специалист должен сообщить об этом и получить полный файл. Если плагин не подключен, он должен сказать, что постоянная память недоступна. Простой просмотр Markdown без начала Work сам по себе консультацию не запускает.

Если выданный файл не виден в «Файлах проекта», вернитесь в установочный Work и попросите повторно выдать именно этот готовый файл поддерживаемым механизмом файлов Work. Не считайте путь /workspace готовым вложением.

## Что подтверждено, а что проверять отдельно

Пользователь сообщил, что в его интерфейсе Work выданные файлы доступны через «Файлы проекта» и используются для старта нового Work. Это основной сценарий данного комплекта. Не приравнивайте его к автоматической загрузке в общие Sources или к установке навыка меню.

Реальные проверки: файл доступен целиком в новом Work; выбран правильный специалист; вызван инструмент именно своего плагина; получены фактические данные. Доступность этого пути на другом аккаунте и телефоне проверяется в его интерфейсе. Общие Sources и инструкция проекта могут использоваться дополнительно, но не являются обязательным условием описанного запуска.
